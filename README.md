# Netflix_content_analysis
**Netflix Content Analysis** (SQL + Python + Power BI)

**Overview**
This project analyzes Netflix Movies and TV Shows data to explore content trends through data cleaning, exploratory data analysis, and visualization.

T**ools Used**: Python (Pandas, NumPy, Matplotlib), SQL, Excel, Power BI

**Project Work**
Cleaned and standardized raw Netflix datasets
Merged Movies and TV Shows into a unified dataset
Performed exploratory data analysis (EDA) in Python
Used SQL for structured analysis of trends, ratings, and genres
Built visualizations and an interactive Power BI dashboard

**Key Learnings & Takeaways**
Handling real-world datasets with missing and inconsistent values
Performing structured end-to-end data analysis workflows
Writing SQL queries for analytical insights
Creating meaningful visualizations for data storytelling
Integrating multiple tools (Python, SQL, Power BI) in one project pipeline

**Conclusion**
This project strengthened my understanding of the complete data analysis process, from raw data preparation to generating insights through visualization. It improved my technical skills as well as my ability to think analytically and work with real-world datasets.
